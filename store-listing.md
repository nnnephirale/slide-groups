# Store listing copy

## Short description (≤132 characters)

Keynote-style slide groups for Google Slides: drag slides into a group, collapse it, and label it.

## Long description

Slide Groups brings Keynote's collapsible slide groups to Google Slides. Drag slides onto another slide to nest them, drag them back out to ungroup, and collapse any group into a single thumbnail so a long deck stays easy to navigate. Name groups with a label right on the thumbnail. Groups can nest inside each other, ⌘Z undoes changes, and your groups sync between your computers through Chrome.
